# EstateFlow System

EstateFlow System is a C# Windows Forms real estate management project using MySQL and ADO.NET style repository logic.

## Main Modules
- Login with role support
- Dashboard statistics
- Property CRUD
- Client CRUD
- Agent CRUD
- Sales records
- Search/filter with DataGridView
- CSV report export
- MySQL database script
- Documentation and deployment guide

## Folder Structure
- Forms: Windows Forms UI and Designer files
- Models: Data entity classes
- Database: MySQL connection and queries
- Reports: Report viewer and CSV export
- SQL: Database migration script
- Documentation: SRS, technical manual, user manual, viva preparation
