# User Manual

## Login
Use username `admin` and password `admin123`.

## Dashboard
Dashboard shows total properties, clients, agents, and sales.

## CRUD Modules
Open Properties, Clients, or Agents from the dashboard. Add data, select a row to edit, update it, or delete it with confirmation.

## Search
Type in the search box to filter DataGridView records.

## Reports
Open Reports and export the sales report to CSV.
