# Technical Manual

## Prerequisites
Install Visual Studio 2022 with .NET Desktop Development and install MySQL Server or XAMPP.

## Setup
1. Open MySQL.
2. Import `SQL/estateflow.sql`.
3. Open the solution file.
4. Restore NuGet packages.
5. Run the project.

## Data Access
The project uses `MySql.Data` package and a small Repository class for reusable database operations.
