# Viva Preparation

## Why MySQL?
MySQL is easy to install through XAMPP, supports relational tables, and is suitable for CRUD based desktop applications.

## Why separate layers?
The project separates UI, Database, Models, and Reports so the code is easier to understand, test, and maintain.

## ADO.NET vs Entity Framework
ADO.NET style code gives more control and is easier to explain in a visual programming semester project. Entity Framework is faster for large projects but adds more abstraction.

## Challenges
Main challenge was keeping form logic clean and avoiding repeated connection code. This was solved using Repository and Queries classes.
